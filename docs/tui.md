# TUI 结构与交互

TUI 使用 `cursive` 的 crossterm 后端实现。入口在 `src/tui/mod.rs`。

## 页面

当前有两个页面：

- 输入页：输入或粘贴要自动输入的文本；空白时显示一行弱提示，说明确认后到目标窗口按 `Ctrl+V` 开始。
- 配置页：用“配置项 / 当前值 / 操作提示”的表格选择“急速 / 一键拟人 / 自定义”预设，或调整中文拆词、符号匹配、输入间隔、词内间隔、错字模拟和错字率。

按 `F3` 在两个页面之间切换。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `F3` | 输入页和配置页切换 |
| `Ctrl+Enter` | 提交文本和配置 |
| `F2` | 提交文本和配置 |
| `Esc` | 输入页下退出 TUI；配置页下返回输入页；输入阶段则中断自动输入 |
| `↑` / `↓` | 配置页选择配置项 |
| `←` / `→` | 配置页切换预设、调整数值或切换开关状态 |

## 模块分工

| 文件 | 职责 |
| --- | --- |
| `mod.rs` | 创建 Cursive、绑定全局回调、输出 `InputSession` |
| `state.rs` | 页面状态和输入结果 |
| `page.rs` | `InputPage` 字段、状态同步、词库摘要 |
| `header.rs` | 顶部框、logo、配置预览、词库提醒 |
| `config_page.rs` | 配置页列表、配置项事件 |
| `view.rs` | `View` trait 实现、布局和页面切换 |
| `render.rs` | 高度常量、颜色、打印工具 |
| `theme.rs` | 透明主题 |

## 布局约束

- TUI 默认全屏铺满终端。
- 顶部区域高度固定为 `HEADER_HEIGHT`。
- 输入区域向下增高。
- 底部提示要始终保留空间，并按当前页面显示不同操作指引。
- 输入框只使用极简上下框线。
- 不要重新引入 TextArea 的不透明背景。

相关代码：

- 高度常量：`src/tui/render.rs`
- 输入区高度计算：`src/tui/view.rs`
- 透明主题：`src/tui/theme.rs`

## 配置页同步

新增配置项或预设时，需要同步修改：

- `src/typing/config.rs`：配置字段和默认值。
- `src/tui/config_page.rs`：配置页显示、选择、切换或调整。
- `src/tui/header.rs`：首页配置预览。
- `src/main.rs`：提交后的命令行确认信息。

预设值和预设名称还需要同步修改 `src/typing/config.rs`。

错字模拟配置还会影响：

- `src/typing/typo.rs`：是否启用错字模拟、错字率命中和计划生成。
- `src/typing/dictionary_typo.rs`：基于词库前缀选择错字候选。

如果配置会影响输入节奏，还要更新：

- `src/typing/timing.rs`
- `src/typing/tests.rs`

## 信息展示

- Header 左侧约占 3/4 宽度，用于显示静态 ASCII logo。
- Header 右侧约占 1/4 宽度，只保留极简状态：预设、速度和词库份数；详细设置留在配置页。
- “符号匹配”只在配置页展示，不加入 Header 右侧摘要。
- 配置页只展示用户能理解的概念，不暴露 token、trie、输入计划等内部实现。
- `skip_word_inner_delay` 在界面上用正向概念“词内间隔”展示：字段为 `true` 时显示关闭，为 `false` 时显示开启。

## 样式约束

- 保持 Claude Code 风格的极简线框。
- 顶部 logo 和配置预览保留。
- 词库状态必须在首页显式显示，但只显示摘要份数。
- 控件文字要能在窄终端下被裁剪而不是破坏布局。
